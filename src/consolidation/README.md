# Consolidation boundary (planned v0.2)

This directory is reserved for offline replay selection, consolidation model
calls, semantic patch validation, and the pure reducer that applies accepted
memory and policy changes.

No sleep or consolidation implementation exists here yet. The module must not
read probes, observer notes, future encounters, or the unrestricted research
archive. Its proposed and policy-generated changes must remain distinguishable
in the accepted operation record.
