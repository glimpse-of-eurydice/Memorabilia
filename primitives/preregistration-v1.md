# v1 preregistration — Layer C holding document

> **Status:** intentionally deferred
> **Gate:** complete only after v0.5 validates the measurement apparatus and
> before confirmatory v1 runs
> **Researcher-only:** this file must never enter a subject workspace.

This file exists to make the deferral explicit. It is not a worksheet to fill
now. Interpretive criteria cannot be credible until v0.5 shows that the
measurement regime can detect a functional graph-context intervention.

## v0.5 gate

Before Layer C is registered, demonstrate with fresh, non-learning probe turns
that:

- graph-derived context is exactly the context recorded in the probe input;
- intact and registered-knockout contexts can produce discriminable behavior
  on a probe designed to depend on that context;
- reinstatement restores the intended context path;
- failures in patch production, retrieval, context delivery, and model
  response can be distinguished;
- probe execution does not mutate the developmental snapshot.

Passing this gate validates an observational/intervention apparatus. It does
not validate Thought Space as a readout of hidden cognition.
